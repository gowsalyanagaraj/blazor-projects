# Blazor Projects

Welcome to my **Blazor Learning Repository!**

This repository contains a collection of hands-on projects developed while learning and exploring different concepts of **Blazor and .NET**.

Each project focuses on a specific Blazor concept or feature. To keep the projects organized and easy to explore, I have maintained each project in a separate Git branch.

## About This Repository

The main goal of this repository is to learn Blazor through practical implementation rather than just theoretical concepts.

Each branch represents an individual project or concept, allowing me to experiment with different Blazor features, understand how they work, and improve my development skills.

## Technologies Used

- C#
- .NET
- Blazor
- Razor Components
- HTML
- CSS
- JavaScript

## Repository Structure

This repository follows a branch-based structure.

- **main** – Contains the repository overview and documentation.
- **Individual branches** – Each branch contains a separate project demonstrating a particular Blazor concept.

## Getting Started

To explore and run any project:

**1. Clone the repository**

```bash
git clone https://github.com/gowsalyanagaraj/blazor-projects.git
```

**2. Navigate to the repository**

```bash
cd blazor-projects
```

**3. Switch to the branch you want to explore**

```bash
git checkout <branch-name>
```

**4. Open the project**

Open the project in Visual Studio or Visual Studio Code.

**5. Restore dependencies and run the application**

```bash
dotnet restore
dotnet run
```

Follow the console output to access the running application.
